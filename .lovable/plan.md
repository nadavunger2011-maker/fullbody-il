
# שיפור דף המוצר - ProductDetail.tsx

## סקירת מצב קיים
דף המוצר הנוכחי כולל:
- גלריית תמונות
- כותרת, תיאור ומחיר
- בחירת וריאנט וכמות
- כפתור "הוסף לעגלה" (עובד אבל נבדוק)
- Trust badges בסיסיים (2 אייקונים)

## שינויים מתוכננים

### 1. שיפור עיצוב כללי
- רקע עדין יותר לאזור פרטי המוצר
- מרווחים ושוליים משופרים
- טיפוגרפיה מודרנית יותר
- תג "מומלץ" או "פופולרי" (אופציונלי)

### 2. בדיקת כפתור הוסף לעגלה
הכפתור נראה תקין בקוד. נוודא:
- שה-Edge Function של Shopify Proxy עובד
- שאין שגיאות ברשת
- נוסיף מצב loading ברור יותר

### 3. הוספת אקורדיון מידע
מתחת לכפתור הוספה לעגלה, נוסיף אקורדיון עם:

| סעיף | תוכן |
|------|------|
| מרכיבים | הרכב המוצר ותכולה |
| אופן השימוש | הוראות לקיחה ומינון |
| אזהרות | מידע בטיחותי חשוב |
| משלוחים והחזרות | מדיניות משלוח ואחריות |

### 4. הוספת Trust Factors מורחבים
מתחת לאקורדיון, בלוק עם 4-6 אייקוני אמון:

| אייקון | טקסט |
|--------|------|
| Truck | משלוח חינם מעל 299 ש"ח |
| ShieldCheck | כשרות למהדרין |
| Clock | אספקה תוך 3-5 ימי עסקים |
| Award | מוצרים באיכות פרימיום |
| RefreshCw | החזרה עד 14 יום |
| HeartHandshake | שירות לקוחות אישי |

## קבצים לעריכה

**`src/pages/ProductDetail.tsx`**
- יבוא רכיבי Accordion מ-`@/components/ui/accordion`
- יבוא אייקונים נוספים מ-lucide-react
- הוספת סקשן אקורדיון אחרי כפתור ההוספה לעגלה
- הוספת Trust Factors section מתחת לאקורדיון
- שיפור עיצוב כללי של הקומפוננטה
