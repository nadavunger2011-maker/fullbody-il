# חיבור Resend ושליחת מיילים לנרשמי /plan

## מה נבנה

### 1. חיבור Resend
נשמור את מפתח ה-API של Resend בצורה מאובטחת בצד השרת (לא בקוד). השליחה תתבצע רק מפונקציית שרת, כך שהמפתח לא נחשף בדפדפן.
כתובת השולח: `FullBody <info@fullbody.co.il>` — הדומיין fullbody.co.il צריך להיות מאומת בחשבון Resend שלך (Domains → Add domain, והוספת רשומות DNS). עד לאימות, שליחה לכתובות חיצוניות תיכשל.

### 2. פונקציית שליחת מייל אחת (גנרית)
פונקציית שרת אחת שמקבלת: סוג המייל, כתובת נמען, ונתונים אישיים (שם, מטרה, קלוריות יעד, ימי אימון וכו'), בונה HTML בעברית (RTL) בעיצוב המותג הירוק של FullBody, ושולחת דרך Resend. כל בקשה מוודאת שהנמען תקין ושסוג המייל מוכר.

### 3. מייל אוטומטי לנרשמים ל-/plan
בסיום השאלון, מיד לאחר שמירת הליד, יישלח מייל אישי לנרשם:
- ברכה בשם הפרטי
- סיכום התוכנית: קלוריות יעד, מאקרו (חלבון/פחמימה/שומן), מספר ימי אימון, רמת ניסיון
- הערה למתחילים על שלב בניית הבסיס (4 שבועות גוף מלא)
- כפתור "חזרה לתוכנית שלי" שמוביל לקישור אישי לצפייה חוזרת בתוכנית
- 2-3 מוצרים מומלצים שהתאמנו לו, עם קישורים לעמודי המוצר באתר
- פוטר עם פרטי המפיץ העצמאי (נדב אונגר, 054-2008578) והבהרת אי-ייעוץ רפואי

השליחה לא תחסום את הצגת התוצאות: אם המייל נכשל, המשתמש עדיין רואה את התוכנית והליד נשמר.

### 4. תזכורות והודעות למשתמשים
- **תבנית תזכורת** נוספת באותה פונקציה: "לא נכנסת מזה X ימים — התוכנית שלך מחכה" עם הקישור האישי.
- **שליחה מהדשבורד**: בלשונית "נרשמים לתוכנית" תתווסף אפשרות לשלוח מייל לליד בודד (תוכנית מחדש / תזכורת), עם סימון של מה נשלח ומתי.
- שליחה אוטומטית מתוזמנת (למשל תזכורת אחרי 7 ימי חוסר פעילות) תישאר לשלב הבא — ניתן להוסיף אחרי שנראה שהשליחה הידנית והאוטומטית מהטופס עובדות תקין.

### 5. מעקב שליחות
טבלה חדשה שמתעדת כל מייל שנשלח: לליד, סוג המייל, זמן שליחה, מזהה מ-Resend, ומצב (נשלח/נכשל). זה מונע כפילויות, ומאפשר להציג בדשבורד מה כבר נשלח לכל ליד.

## פרטים טכניים

- סוד: `RESEND_API_KEY` (נבקש ממך להזין אותו בטופס מאובטח).
- Edge Function חדשה `send-plan-email`: CORS מלא, ולידציית קלט, קריאה ל-Resend API, כתיבת רשומה ל-`email_sends`, והחזרת שגיאת הספק במלואה במקרה כישלון.
- תבניות HTML בעברית עם `dir="rtl"` בקובץ `_shared` נפרד, כדי שיהיה קל להוסיף תבניות נוספות.
- מיגרציה: טבלה `email_sends` (id, lead_id FK, template, recipient, provider_message_id, status, error, created_at) עם RLS — קריאה למשתמש מחובר בלבד, כתיבה ל-service_role בלבד, כולל GRANTים.
- `src/pages/PlanWizard.tsx`: קריאה ל-`send-plan-email` אחרי יצירת הליד (best-effort, לא חוסמת UI).
- `src/components/admin/AdminLeads.tsx`: כפתור שליחת מייל בכרטיס הליד + הצגת היסטוריית שליחות.
- אין שינוי בעמוד הבית, בקטלוג או בעמודי המוצר.
